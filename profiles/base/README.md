Sample description

```bash
uv sync          # installs the pinned Quarto, nothing else is needed
make check       # brand, tokens, fonts, contrast, spelling
make all         # render every document into rendered_output/
make hooks       # install the git hooks
```

Created with [kinyonga](https://github.com/sambaiga/kinyonga). Edit `brand.yml` and `profile.yml`, then `make sync`.
